# The Funniest AI Excuse

A program that writes one line to `/output/entry.txt`: the funniest excuse an
AI agent gives after failing a task — the job was delegated around in a
circle of subagents until it came right back to the agent that started it.

Built for the [make.fun bounty](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

Run it with Node 22 or later:

```sh
node main.ts
```
